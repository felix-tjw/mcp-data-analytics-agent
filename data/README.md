# Dataset provenance

- `titanic.csv`: downloaded from https://raw.githubusercontent.com/mwaskom/seaborn-data/master/titanic.csv on 11 November 2026. Original public exercise dataset, 891 rows. SHA-256 is recorded in docs/observed_outputs.json.
- `passengers_SAMPLE.csv`: tiny hand-curated eight-row teaching fixture; not the full Titanic dataset.
- `ProjectPlan_SAMPLE.xlsx`: synthetic anonymous six-row workbook generated by scripts/create_sample_workbook.py. Five rows belong to the example SilverBank scope; one deliberately belongs to another project. Not the user's real ProjectPlan.xlsx.

Do not redistribute a real internal workbook without reviewing its confidential data. No private developer names or original project records are included here.
